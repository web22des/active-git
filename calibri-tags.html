Теги для библиотеки Calibri

Группа 1: Жанр и Поджанр (Самая важная)

Это основа каталога. Лучше использовать один основной жанр, а поджанры добавлять через точку или двоеточие (например, Фантастика.Космоопера или Фантастика:Космоопера), если не хочешь плодить сотни тегов.

Художественная литература:

  • Проза
  • Современная проза
  • Классика
  • Детектив -> (Иронический, Полицейский, Нуар, Триллер)
  • Фантастика -> (Научная, Космоопера, Киберпанк, Постапокалипсис, Альтернативная история, ЛитРПГ)
  • Фэнтези -> (Городское, Эпическое, Тёмное, Героическое, Славянское, Юмористическое)
  • Роман (или Любовный роман) -> (Современный, Исторический, Young Adult)
  • Приключения
  • Ужасы / Мистика
  • Поэзия / Драматургия

Нон-фикшн (Non-fiction):

  • Биография / Мемуары
  • История
  • Психология -> (Саморазвитие, Отношения)

  • Наука -> (Физика, Астрономия, Биология)
  • Технологии -> (ИТ, Программирование, Искусственный интеллект, DIY)
  • Философия
  • Эзотерика / Религия
  • Публицистика
  • Научпоп
  • Справочник
